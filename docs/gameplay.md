## 設計靈感

| 參考 | 借用的核心概念 | 在笨笨掃地機的對應 |
|---|---|---|
| 《教妹妹開車》（Easy Fox，語音指揮駕駛模擬） | 玩家坐副駕駛、**只能動口不能動手**；對方不會百分之百照做、會有哭笑不得的反應；語氣太兇會鬧情緒；宣傳詞「挑戰副駕哥哥的血壓極限」；從練習場到充滿突發狀況的真實道路 | 只能打字指揮笨笨；**心情系統**（語氣影響聽話程度、會頂嘴罷工）；**主人血壓計**（爆表＝失敗）；**新手訓練場 → 突發事件越來越多的關卡** |
| 《Suck Up!》等 LLM 遊戲 | 把 LLM 當成「要克服的對象」而不只是聊天；回應速度影響沉浸感 | LLM 是笨笨的大腦，玩家要學會「怎麼說它才聽得懂」；背景執行緒＋思考中動畫隱藏延遲 |
| 掃地機器人的經典迷因 | 輾過狗便便抹得滿地都是 | 💩 狗便便障礙物、成就「抽象畫家」 |

## 核心循環

```
看畫面 → 想好怎麼說（內容＋語氣）→ 笨笨理解（LLM）→ 執行 → 出包或成功 → 心情／血壓／分數變化 → 再說下一句
```

玩家的決策有兩層：
1. **說什麼**：一句話塞多少動作？繞過貓還是賭一把？先回充還是先吸完？
2. **怎麼說**：要不要說「請」？笨笨鬧彆扭時要先哄它還是直接用「停」「回充」保底？

## 系統一覽

### 💗 心情（`bendan/gameplay/mood.py`）

| 等級 | 心情值 | 賣蠢強度 | 拒絕機率 | Prompt 指示 |
|---|---|---|---|---|
| 😄 開心 | ≥ 80 | −1 | 0% | 很願意配合，語氣輕快 |
| 🙂 普通 | 50–79 | ±0 | 0% | — |
| 😒 不爽 | 25–49 | +1 | 12% | 照做但帶點委屈、酸主人 |
| 😤 鬧彆扭 | < 25 | +2 | 45% | 頂嘴，要主人說「請」或道歉 |

語氣分析（規則式，穩定可重現）：

| 語氣 | 例子 | 心情 | 主人血壓 |
|---|---|---|---|
| 有禮貌 | 請、麻煩、謝謝 | +4/個（最多 +8） | — |
| 稱讚 | 好棒、厲害、好乖 | +8/個（最多 +16） | — |
| 道歉 | 對不起、抱歉 | +12 | — |
| 罵人 | 笨蛋、白痴、廢物 | −15/個（最多 −30） | +3 |
| 催促 | 快點、趕快、到底 | −5 | +2 |
| 大吼 | 三個以上驚嘆號 | −4 | +2 |
| 一直重複 | 跟上一句一模一樣 | −3 | — |

規則：句子裡有好聽話（且沒罵人）→ 這次**一定不會被拒絕**；「停」「回充」永遠有效（安全保底）。
事件也會影響心情：踩樂高 −6、輾便便 −8、吸乾淨 +3、充飽電 +6、過關 +10。

**拒絕是遊戲機制決定的**（固定機率、可重現），LLM 只負責「演」出頂嘴的台詞——
這樣既保證玩法穩定，又保留 LLM 的即興感。

### 🔋 電量（`bendan/world/game.py`）

走一格 −1、轉向 −0.2、吸一次 −2、吸到水 −10。低於 25%、**或剩下的電只夠走回充電座**時警告（v3）並閃紅燈；歸零失敗。踩到充電座自動充飽。
第 5 關電池只有 60，**必須中途回充**。

### ⭐ 分數與星級（`bendan/gameplay/scoring.py`）

### 🙃 恍神（v3，`bendan/gameplay/quirks.py`）

LLM 給的計畫在執行前，有一定機率被笨笨自己改掉（**程式決定**，不是叫 LLM 演——實測 7B 模型太乖，Prompt 叫它偶爾不聽話它也照做）：

| 怪癖 | 效果 |
|---|---|
| 🙃 左右不分 | 左轉、右轉全部對調 |
| 🛞 煞車失靈 | 某一段前進多走 1–2 格 |
| 🦥 偷懶少走 | 某一段前進少走 1 格 |
| 🫥 忘記吸 | 走到了卻沒吸 |
| 😪 做一半就累了 | 後半段動作不做 |
| 🌀 多轉一下 | 做完順便轉 90°（下一句要注意朝向） |
| 🙉 裝沒聽到 | 整句不做 |

**機率 = 關卡設定 × 心情倍率**（開心 ×0.5、普通 ×1、不爽 ×1.5、鬧彆扭 ×2；正經模式再 ×0.5；上限 80%）。
所以「好好說話」不只是禮貌，而是降低恍神率的策略。「停」「回充」永遠不會被改。恍神時畫面和指令紀錄都會標出來。

### 🧠 其他難度機制（v3，關卡參數）

| 參數 | 效果 | 從第幾關開始 |
|---|---|---|
| `command_limit` | 指令上限，用完還沒過關就失敗 | 3 |
| `max_plan` | 一次只記得幾個動作，多講的會忘掉（🧠） | 5（6 個）、8（3 個）、10（4 個） |
| `route_hints: False` | **導航壞了**：笨笨不會自己算去灰塵的路線，要玩家指路 | 6 |
| `step_limit` | 步數上限＝時間限制 | 6、10 |
| `mood_start`／`fatigue` | 一開始就不爽；每下一句話心情 −N（會累） | 7、10 |
| `guardrail: False` | 這關不能開禁區護欄 | 8、10 |
| `dark`／`vision` | 停電：畫面只看得到笨笨附近、走過的地方；笨笨也只看得到 N 格內 | 9（`vision` 也用在 10） |

### 🧭 方向標示（v3，`bendan/render/board.py`）

玩家回饋「看不出笨笨面向哪裡」。畫面改成 SVG，並加上：
- 笨笨頭上的**黃色大箭頭**＝正前方，前方那一格整格發亮
- **前方格子標 1、2、3…**，標到會撞到的東西為止 → 直接看出「往前走幾格」
- 笨笨的**左手邊、右手邊、後方**標「左」「右」「後」（是笨笨的左右，不是螢幕的左右）
- 角落的**指北針**，笨笨面向的方位標成黃色；右側面板寫「面向東 ➡｜前方可走 3 格（再過去是貓）」
- 「🔄 視角」可以切換成**俯視**（上方＝北），等角視角看不習慣時用

### 🪟 遊戲視窗（v3，`bendan/ui/widget_mode.py`）

一個畫面裡有遊戲畫面、右側狀態面板、對話框、輸入框，以及**對話框下方的指令紀錄**（你說了什麼 → 笨笨回什麼、做了什麼、有沒有恍神 → 結果）。
「🪟 彈出成獨立視窗」會把整個遊戲搬到一個新的瀏覽器視窗，關掉就回到 Notebook；也可以「⛶ 全螢幕」。
鍵盤：Enter 送出（中文輸入法選字時不會誤送）、Esc＝停、↑／↓ 叫出之前的指令。

### 🛡️ 護欄模式（`/guard`）

新手友善選項：開啟後，笨笨的計畫如果會闖進禁區，程式會在前一步把它攔下（事件「🛡️ 護欄攔下」）。
預設關閉——因為「明明說不准進臥室，它還是衝進去」本身就是笑點（血壓 +18）。

### 🧭 路線提示（只在前 6 關）

玩家說「去吸最近的灰塵」時，7B 模型實測幾乎都規劃錯、一路撞牆，只有挫折沒有笑點。
所以前幾關會在世界描述附上算好的路線，「蠢」留給人設和心情去演。
v3 發現這也讓遊戲「太簡單」——一直說「去吸最近的灰塵」就能過關，所以**第 6 關起關掉**（導航壞了，要玩家指路）。

## 平衡調整

實測後的調整：一句話對心情的影響上限 ±25（原本一句「笨蛋白痴快點」就 −35，太難哄回來）。
v3：恍神、記性差、導航壞掉、停電等難度機制；用 `scripts/difficulty_probe.py` 讓腳本玩家跑每一關檢查難度曲線（結果見 [difficulty.md](difficulty.md)）。

所有數值都集中在模組頂端的表格（`TIERS`、`EVENT_MOOD`、`EVENT_BP`、`PENALTY`、關卡設定），改一個數字即可。
建議用 `03_評估.ipynb` 的「心情 vs 照做率」實驗搭配試玩問卷一起調。
